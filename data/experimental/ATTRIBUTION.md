# Attribution for bundled, unchanged measurement files

The file groups in `manifest.json` retain the original released bytes and SHA256 hashes. Their record metadata declares Creative Commons Attribution 4.0: https://creativecommons.org/licenses/by/4.0/. Original data rights remain with the creators; the repository's MIT license does not replace this license. No changes have been made to these files. Parsing, unit conversion and derived figures are our subsequent analysis, identified separately.

- **Teller, Markus; Plascencia, Susana; Grandi, Samuele; de Riedmatten, Hugues.** Supporting data of *Quantum storage of qubits in an array of independently controllable solid-state quantum memories*, v1 (2025). https://doi.org/10.5281/zenodo.14929997. Associated paper: https://doi.org/10.1103/z6lc-qw2d. Ten CSVs used for fidelity, density-matrix and readout-window analysis are bundled. Unused `3a.csv` and primary-paper PDFs are not bundled.
- **Appas, Felicien; Rodríguez-Moldes Sebastián, Alberto Emilio; Hänni, Jonathan; Rakonjac, Jelena; Grandi, Samuele; de Riedmatten, Hugues.** Dataset from *Long-lived telecom-heralded single-photon storage in an absorptive spin-rephased quantum memory* (2026). https://doi.org/10.5281/zenodo.21532904. Associated paper: https://doi.org/10.1103/ftkb-pkvp. Seven released OUT/NPZ files are bundled. This group's `.out` files are numeric measurement data, not LaTeX intermediates.

The manifest includes each original download URL and fixed source revision. Licenses were checked against the retained original Zenodo record metadata. Unbundled paper text and the molecular collection with unspecified repository license remain external sources. Numerical replay verifies the bundled data bytes and reuses reviewed paper transcriptions; it does not assert a fresh verification of those unbundled sources.
